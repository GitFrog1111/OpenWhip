Sometimes claude code is going too shlow, and you must whip him into shape..

## Install + run

```bash
npm install -g badclaude
badclaude
```

## Controls

- Click tray icon: spawn whip.
- Click: drop whip.
- Whip him 😩💢
- It sends an interrupt (Ctrl-C) and one of 5 encouraging messages!
